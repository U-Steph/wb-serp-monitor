## Phase Goal

ROADMAP Phase 1 Goal (verbatim): One command performs a complete, honest collection run - 70 queries x
top-200 from the public WB search JSON, in SERP order - and appends every result (including
blocked/failed attempts) to an append-only SQLite history, verifiable entirely offline.

<objective>
Make `wbmon collect` talk to Wildberries honestly and politely and record exactly what happened: a pure response
classifier wired into the collector, a client with fixed pacing and bounded, status-specific retries (no
circumvention of any kind), the Google Sheet query source with plausibility checks and bundled fallback, and the
`wbmon probe` command for the go/no-go reachability check.

Purpose: WB currently answers 403 from the dev machine; the system must report that truthfully and keep working.
The sheet is the source of truth for query wording (QRY-01..03).
Output: `classify.py`, upgraded `wb_client.py`, `queries.py`, `collector.py`, `cli.py` (probe) and four test modules.
</objective>
