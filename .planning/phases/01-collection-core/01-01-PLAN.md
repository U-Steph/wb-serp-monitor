## Phase Goal

ROADMAP Phase 1 Goal (verbatim): One command performs a complete, honest collection run - 70 queries x
top-200 from the public WB search JSON, in SERP order - and appends every result (including
blocked/failed attempts) to an append-only SQLite history, verifiable entirely offline.

Note: ROADMAP marks the phase `**Mode:** mvp` but the Goal line is outcome-form, not "As a / I want to /
so that" form; no user story was invented here (user-story-template rule). Walking-skeleton shape follows
D-A10.

<objective>
Build the walking skeleton (D-A10): project scaffold, the full frozen schema (migration 1, D-A1), the shared
dataclass contracts, `wbmon init-db`, and a thin but real `wbmon collect --limit-queries 1` path that runs
end-to-end against an `httpx.MockTransport` page-1 fixture, writes a real run / run_query / observations into a
temporary DB and prints the run summary read back from that DB.

Purpose: every later Phase 1 plan widens this exact path; Phases 2 and 3 build on its schema and CLI. Freezing
`models.py`, `config.py`, `migrations.py` and `tests/factories.py` here is what lets plans 01-02, 01-03 and
01-04 run in parallel on disjoint files.
Output: installable `wbmon` package, offline test harness, SKELETON.md decisions realised in code.
</objective>
