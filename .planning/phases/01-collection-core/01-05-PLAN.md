## Phase Goal

ROADMAP Phase 1 Goal (verbatim): One command performs a complete, honest collection run - 70 queries x
top-200 from the public WB search JSON, in SERP order - and appends every result (including
blocked/failed attempts) to an append-only SQLite history, verifiable entirely offline.

<objective>
Close the phase goal: `wbmon collect` paginates every query to top-200 using the pure pager, isolates failures per
query, stops hammering a blocking WB with the circuit breaker, bounds run time with the deadline, holds the run
lock, recovers crashed runs as `abandoned`, honours scheduler slots, logs every run and query, and exposes the
final CLI contract Phase 2's scheduler will call (`collect --trigger scheduler --slot ISO`). End-to-end CLI tests
and a CI workflow prove all of it offline on Python 3.11/3.12/3.14.

Purpose: this is the "one command performs a complete, honest collection run" of the ROADMAP goal.
Output: final `collector.py`, `orchestrator.py`, `cli.py`, three test modules, `.github/workflows/ci.yml`.
</objective>
