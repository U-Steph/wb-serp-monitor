## Phase Goal

ROADMAP Phase 1 Goal (verbatim): One command performs a complete, honest collection run - 70 queries x
top-200 from the public WB search JSON, in SERP order - and appends every result (including
blocked/failed attempts) to an append-only SQLite history, verifiable entirely offline.

<objective>
Make the history `wbmon collect` writes provably durable and append-only: prove the schema guarantees through the
real connection recipe, harden the writer (atomic per-query write with a visible failure row, crash recovery via
abandon_stale_runs, finished-run guard), add the advisory run lock (D-A7) and the STOR-04 read paths with a
2.35M-row performance proof.

Purpose: "history is never lost or fabricated" is the core value; this plan turns it from a promise into tested
database behaviour. Plan 01-05 wires the lock and abandon step into `collect`; Phase 3 builds on the reader.
Output: hardened storage package, lock module, four storage test modules (one marked slow).
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| application code -> SQLite file | the collector is the only writer; history must never be rewritten or partially written |
| concurrent processes -> same DB | manual collect, scheduler subprocess and UI reader may overlap |
| query text / WB strings -> SQL | untrusted strings reach SQL statements as values |
