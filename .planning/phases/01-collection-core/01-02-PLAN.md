## Phase Goal

ROADMAP Phase 1 Goal (verbatim): One command performs a complete, honest collection run - 70 queries x
top-200 from the public WB search JSON, in SERP order - and appends every result (including
blocked/failed attempts) to an append-only SQLite history, verifiable entirely offline.

<objective>
Widen the walking skeleton so every observation `wbmon collect` writes carries the real field values the TZ asks
for (price, rating, reviews, delivery days, seller, ad flags) with explicit NULLs for anything unavailable, and
build the pure top-N pagination state machine that plan 01-05 wires into the collector.

Purpose: DATA-01..07 are the content of the history; they are non-backfillable, so the mapping must be right
before the first real run. COL-02's error-prone stop/numbering rules live in a pure module that is tested
exhaustively without HTTP.
Output: complete `normalize.py`, new `delivery.py` and `pager.py`, four JSON fixtures, three test modules.
</objective>
