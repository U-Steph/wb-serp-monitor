## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Anti-bot bypass | Building a browser/token path to get past WB's wbaas check | blocking | Only `wbmon probe` / plain httpx; on 403/498 record `blocked`, report to the user |
| `.env*` writes | Write tool refuses `.env*` (user deny rule) | blocking | Use README «Конфигурация» + CLI env; user creates `.env.example` themselves if wanted |
| compose `build:` on one service | Moving `build:` only to init-db risks "pull access denied" on a clean host | advisory | Keep the `x-wbmon` anchor with `build:` on every service (IN-01 fix was reverted) |
| Worktree editable-install trap | In a sibling worktree, `import wbmon` resolves to the main checkout via the editable install | advisory | Run tests with `PYTHONPATH="$WT/src"` and the main `.venv` python |
| Worktree path guard | A shell cwd left inside a worktree blocks Write to the main repo (GSD hook) | advisory | `cd` back to the main repo root before writing there |
| zsh shell gotchas | `$VAR` with spaces is not word-split (exit 127); a variable named `path` clobbers `$PATH`; unmatched globs error out | advisory | Use shell functions, never name a var `path`, guard globs |
| Subagent report files | One subagent's Write of `SUMMARY.md` was refused ("return findings as text") | advisory | Ask agents to return the content under `## SUMMARY CONTENT`; orchestrator writes it |
