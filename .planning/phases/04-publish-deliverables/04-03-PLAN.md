## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| local repository -> GitHub (public or private) | the full history, `.planning/` included, becomes visible |
| local repository -> zip archive | the archive is sent to a third party |
| host database -> documents | numbers and claims in the documents must match the real history |
| this Mac -> host (SSH, read-only report) | the report runs inside the collector container or as wbserp |
| message file -> employer | the text leaves the user's control once sent |
