## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| this Mac -> VPS (SSH) | the executor runs privileged commands on the user's server |
| host -> Wildberries | real requests leave from the user's IP under the honest User-Agent |
| internet -> host public port | anyone can open the UI link |
| host -> Docker Hub, PyPI, distro repositories, mirrors | code and images enter the host |
| tracked files -> public repository | the SUMMARY and docs are published in 04-03 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-10 | Spoofing / Information Disclosure | SSH access | mitigate | key-based `ssh -o BatchMode=yes` only; passwords and private keys are never requested or stored; SSH user, port and target live only in the untracked `../wbmon-deploy/notes.md`; acceptance greps tracked files for SSH details |
| T-04-11 | Elevation of Privilege | sudo on the host | mitigate | only the actions permitted in Task 1 (named apt packages, one firewall port, optional reboot); services run as uid 10001 in containers or as the system user wbserp with the systemd sandbox |
| T-04-12 | Information Disclosure | public UI port | mitigate | only 8501 (or 80/443 with Caddy and WEB_BIND=127.0.0.1) is opened; the UI is read-only at the SQLite level and hides error details |
| T-04-13 | Policy violation (circumvention) | collector on the host | mitigate | the plain httpx client is unchanged; one probe, no retry loops; a block leads to the Task 3 user decision, whose options exclude proxies, VPN changes, browsers, other user agents, cookies and tokens |
| T-04-14 | Tampering / Repudiation (history loss, synthetic data) | restart test, manual run | mitigate | never `down -v`; restart only between runs; the only manual write is one real `wbmon collect --slot` after an ok probe; report integrity counters must be 0 |
| T-04-15 | Denial of Service (load on WB) | collection | mitigate | fixed 1.5 s delay, breaker after 3 blocked queries, at most one manual run, scheduler once per hour |
| T-04-16 | Information Disclosure | `.env` handling | mitigate | no `.env*` file locally or on the host; variables passed on the command line and recorded in the untracked notes |
| T-04-SC | Tampering (supply chain) | images, apt and pip on the host | mitigate | pinned image tags python:3.12-slim and caddy:2.11-alpine; mirrors only when the user names them; apt only from the distro repositories with permission; pip installs only the project's existing dependencies |
</threat_model>
