Facts to document (verify each against the merged code before writing; the merged files win on any difference):

CLI (`wbmon` console script and `python -m wbmon`, src/wbmon/cli.py):
- `wbmon init-db [--db PATH]` creates or migrates the database; safe to re-run.
- `wbmon collect [--db PATH] [--top-n N] [--limit-queries N] [--trigger manual|scheduler] [--slot ISO-8601-with-offset]`
  performs one run with REAL requests; `--trigger scheduler` requires `--slot`; the slot is floored to the hour and a
  slot that already has a run is skipped with exit 0; SIGTERM closes the run honestly (`terminated` attempts, 02-03).
- `wbmon probe [--query TEXT]` sends exactly one page-1 request without retry, prints one JSON line (outcome,
  error_class, http_status, server, content_type, products, normquery, shape, elapsed_ms, attempts, endpoint, params,
  user_agent, message) and writes nothing.
- `wbmon scheduler [--db PATH]` runs forever: at every :00 Europe/Moscow it starts a fresh child
  `python -m wbmon collect --trigger scheduler --slot {slot}`; catch-up of the current slot only within 45 minutes;
  never back-fills; never overlaps (file lock `{db}.lock` + UNIQUE slot); forwards SIGTERM to the child; runs init-db
  itself; writes the heartbeat `scheduler_heartbeat.json` next to the database at least every 30 s.
- `wbmon healthcheck [--db PATH] [--max-age SECONDS]` exits 0 when the heartbeat is fresh, 1 otherwise (never 2);
  default max age is `wbmon.health.DEFAULT_MAX_AGE_S`.
- Exit codes: 0 success (collect is also 0 when every query was blocked, when the lock is busy, when the slot exists),
  2 usage or configuration error, 1 crash.

Settings (src/wbmon/config.py; an empty value means unset; an invalid value exits 2 naming the variable):
WBMON_DB_PATH `data/wbmon.sqlite3` (Docker pins `/data/wbmon.sqlite3`), WBMON_TOP_N `200` (1..1000), WBMON_DEST
`-1257786` (Moscow), WBMON_SEARCH_URL `https://search.wb.ru/exactmatch/ru/common/v18/search`, WBMON_REQUEST_DELAY
`1.5` s (minimum 0.5, fixed, no jitter), WBMON_RUN_DEADLINE `2400` s, WBMON_SHEET_CSV_URL (Google Sheet id
`1K0m4229w_1LONgrNzWpx8lkkDcAlbdZH5ifHenZV3x8`, `export?format=csv`), WBMON_USER_AGENT (default
`Mozilla/5.0 (compatible; wbmon/{version}; +{REPO_URL})`), WBMON_TIMEZONE `Europe/Moscow`, WBMON_LOG_LEVEL `INFO`.
Fixed WB parameters: ab_testing=false, appType=1, curr=rub, lang=ru, locale=ru, resultset=catalog, sort=popular,
spp=30, suppressSpellcheck=false, plus dest, page, query (query passed byte-for-byte).

Collector behaviour: sequential requests with the fixed delay; pages until top_n, an empty page or a page-1
wrap-around; 403/498/HTML-at-200/redirect -> `blocked`, 429 -> `rate_limited` (Retry-After honoured at most once),
5xx/timeouts -> up to 2 bounded retries then `error`; 200 with zero products -> `error`; circuit breaker after 3
consecutive blocked queries records the rest as `blocked`/`circuit_open` without requests; run deadline -> remaining
queries `error`/`deadline`. Run statuses: running, ok, partial, blocked, error, abandoned. Query statuses: ok, partial,
blocked, rate_limited, error. Error classes: `wbmon.models.ERROR_CLASSES`.

Compose (compose.yaml): services init-db (one-shot), collector (`wbmon scheduler`, healthcheck via
`wbmon healthcheck`), web (Streamlit from /app), caddy (profile `tls`); named volume `wbmon_data`; pinned
WBMON_DB_PATH=/data/wbmon.sqlite3 and TZ=Europe/Moscow; json-file logs 10m x 3; variables `WEB_BIND` (0.0.0.0),
`WEB_PORT` (8501), `SITE_ADDRESS` (:80), `PYTHON_IMAGE` (python:3.12-slim), `CADDY_IMAGE` (caddy:2.11-alpine),
`PIP_INDEX_URL` (https://pypi.org/simple); `COMPOSE_PROFILES` (empty; `tls` starts Caddy); optional `.env` needs
Compose >= 2.24. Never `docker compose down -v` (deletes the history volume).

Makefile targets: help, install, test, lint, init-db, collect-once, scheduler, web, up, up-prebuilt, down, logs, ps.

UI (Phase 3, src/wbmon/ui/): Russian Streamlit app with tabs «📈 Позиции», «🗂 Выдача», «🩺 Журнал сборов»,
«ℹ️ О сервисе»; read-only (`mode=ro` + `PRAGMA query_only=ON`, short-lived connections, cache keyed on the latest
data); freshness badge, collector heartbeat line, status banners for blocked/partial runs; honest gaps (a product
absent from a complete ok run is a gap; blocked/partial/error runs are grey bands); CSV export (`;`, UTF-8 with BOM).
Read the merged app.py and 03-0*-SUMMARY.md for the final wording.
