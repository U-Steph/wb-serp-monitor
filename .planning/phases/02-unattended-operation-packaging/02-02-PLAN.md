## Phase Goal

ROADMAP Phase 2 Goal (verbatim): The collector runs by itself every hour on the Moscow clock, survives
failures and restarts without manual intervention, and the whole stack starts with one
`docker compose up -d` (or without Docker for local development).

<objective>
Package the project so an operator can (1) build one image that runs every role, (2) start the whole stack —
init-db, collector, web, optional Caddy — with one `docker compose up -d` on one named volume, and (3) run the
same project without Docker through a venv and a Makefile, with every setting documented in `.env.example`.
Docker is not installed on the dev machine, so every artifact is validated statically (official compose-spec
schema, Dockerfile parser, Makefile/env checks); the real `docker compose up` happens in Phase 4 on the host.

Purpose: OPS-01 (image, compose, named volume, restart policy, healthchecks, log rotation, Moscow scheduling
with UTC storage, tzdata) and OPS-02 (local no-Docker path, documented `.env.example`).
Output: `Dockerfile`, `.dockerignore`, `compose.yaml`, `deploy/Caddyfile`, `.env.example`, `Makefile`,
dev extra in `pyproject.toml`, vendored `tests/data/compose-spec.json`, `tests/test_packaging.py`.
</objective>
