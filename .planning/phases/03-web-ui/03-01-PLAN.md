## Phase Goal

ROADMAP Phase 3 Goal (verbatim): A Russian-language Streamlit app lets the user pick a query and products and
see an honest, readable history of positions - gaps where a product was not found, clear markers where we could
not look - plus the collected characteristics and the run log.

Note: ROADMAP marks the phase `**Mode:** mvp` but the Goal line is outcome-form, not "As a / I want to / so
that" form; no user story is invented here (user-story-template rule, same handling as Phase 1).

**Vertical slices of this phase (MVP_MODE, sequential executors, each plan widens the same running page):**

| Plan | Wave | After it, a visitor of the page can… |
|------|------|--------------------------------------|
| 03-01 (this) | 1 | open the read-only app and see how fresh and how trustworthy the data is (freshness badge, collector line, blocked/partial banner, totals) and the run log table — exactly what the likely all-blocked review state needs |
| 03-02 | 2 | pick a query and products and read the honest position chart (gaps, grey failed-run bands, ad diamonds, period filter) |
| 03-03 | 3 | read characteristics and full history, download the CSV, browse the full top-N SERP of any run («🗂 Выдача») |
| 03-04 | 4 | see the query × run status heatmap and «ℹ️ О сервисе»; responsiveness on a week of data is proven; full gate + end-of-phase human check |

<objective>
Build the first vertical slice of the Streamlit UI: the read-only app shell that already answers the reviewer's
first question — "is this data fresh and real?" — end to end (browser → app.py → cached loaders → connect_ro →
SQLite): page config, title/caption, freshness badge, collector heartbeat line, the single status banner, sidebar
totals, the «🩺 Журнал сборов» run table, every empty/blocked state of the header, and the test infrastructure all
later plans reuse (D3-A1 guardrail amendment, temp-only scenario DB builder, AppTest harness).

Purpose: core value "the UI shows history honestly" starts with an honest header; the review DB may contain only
blocked runs, and this slice makes that state complete and informative. It also fixes the cache-keying and
read-only patterns (STOR-05, UI-12) that every later loader copies.
Output: `src/wbmon/ui/{__init__,data,texts,series,app}.py`, `.streamlit/config.toml`, `tests/ui/*` harness and
tests, amended `tests/test_guardrails.py`.
</objective>
