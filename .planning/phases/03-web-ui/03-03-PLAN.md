## Phase Goal

ROADMAP Phase 3 Goal (verbatim): A Russian-language Streamlit app lets the user pick a query and products and
see an honest, readable history of positions - gaps where a product was not found, clear markers where we could
not look - plus the collected characteristics and the run log.

Note: Goal line is outcome-form, not user-story form; no user story is invented (same handling as Phase 1).
Slice map: 03-01 shell/header/run log → 03-02 honest chart → **03-03 (this) characteristics, history, CSV,
«Выдача»** → 03-04 heatmap/«О сервисе»/perf/gate.

<objective>
Widen the page with everything the user needs to inspect the selected products and the raw SERP: the
characteristics table, the full observation history, the Excel-friendly CSV export (all three respecting the
period), the recent-attempts table for queries without data, and the «🗂 Выдача» tab with the full top-N snapshot
of any stored run — end to end (cached loaders → pure shaping in series.py → st.dataframe / download button).

Purpose: UI-07, UI-08, UI-11 and the table/CSV half of UI-09; the attempts table makes the likely all-blocked
review state explain itself on every tab.
Output: shaping functions + tests, three loaders, the extended «Позиции» tab and the new «Выдача» tab.
</objective>

1. D3-A7 — CSV file name slug is `q{sheet_order:02d}` (`wb_serp_q01_20261016_1430.csv`) instead of UI-SPEC's

3. Planner choice (RESEARCH Pitfall 3) — every `st.dataframe` uses `placeholder="—"` because Streamlit 1.66 prints
   «None» in NULL cells otherwise; numeric columns stay numeric/sortable but a NULL cell therefore shows «—», not an

4. Planner choice (RESEARCH Pitfall 5) — the export caption gains one honesty sentence about formula
   neutralisation: «… — открывается в Excel. Ячейки, начинающиеся с «=», «+», «-», «@», экранированы апострофом.»
5. Time columns use `DatetimeColumn(format="DD.MM.YYYY HH:mm")` on tz-naive МСК datetimes — same visible format as
