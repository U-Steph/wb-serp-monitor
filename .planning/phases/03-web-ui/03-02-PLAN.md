## Phase Goal

ROADMAP Phase 3 Goal (verbatim): A Russian-language Streamlit app lets the user pick a query and products and
see an honest, readable history of positions - gaps where a product was not found, clear markers where we could
not look - plus the collected characteristics and the run log.

Note: Goal line is outcome-form, not user-story form; no user story is invented (same handling as Phase 1).
Slice map: 03-01 shell/header/run log → **03-02 (this) honest position chart** → 03-03 tables/CSV/«Выдача» →
03-04 heatmap/«О сервисе»/perf/gate.

<objective>
Add the core-value slice: the visitor picks a query (sidebar), a period and products, and reads an honest
interactive position chart — position 1 on top, Moscow time, gaps where a product was not found, grey bands where
the query could not be looked at, diamonds for ads — end to end (sidebar widgets → new cached loaders → pure
honest-gap series → pure Plotly builder → `st.plotly_chart`).

Purpose: this is the project's core value ("gaps where a product was not found — never invented positions").
Output: chart loaders in `data.py`, the FOUND/ABSENT/UNKNOWN state machine in `series.py`, `charts.py`, the
«📈 Позиции» tab and sidebar controls in `app.py`, tests.
</objective>
