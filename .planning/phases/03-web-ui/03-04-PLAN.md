## Phase Goal

ROADMAP Phase 3 Goal (verbatim): A Russian-language Streamlit app lets the user pick a query and products and
see an honest, readable history of positions - gaps where a product was not found, clear markers where we could
not look - plus the collected characteristics and the run log.

Note: Goal line is outcome-form, not user-story form; no user story is invented (same handling as Phase 1).
Slice map: 03-01 shell/header/run log → 03-02 honest chart → 03-03 tables/CSV/«Выдача» → **03-04 (this) run-health
heatmap, «О сервисе», guardrails, week-scale proof, full gate, end-of-phase human check**.

<objective>
Finish the phase: the visitor sees collection health for every query at a glance (heatmap with colour + glyph,
summary badges, legend) and a short methodology page; then the phase is hardened and proven — a source-level
read-only/injection guard, the full State Matrix in AppTest, UI-12 responsiveness on a generated week of data, the
complete repository gate (incl. a Python 3.12 run and a real headless server start), and the end-of-phase human
visual check on temporary databases only.

Purpose: UI-10 (heatmap half), UI-12 (week-scale), UI-01 (all states), STOR-05 (provable no-write path).
Output: heatmap loader/builder, the final four-tab app, `tests/ui/test_ui_guardrails.py`, `tests/ui/test_perf.py`,
a `visual_check` scenario in the temp-only builder.
</objective>
